## Qué es
PANTALLA: Gestión de tareas
El profesor puede crear tareas, asignarlas a uno o varios estudiantes, ver
las entregas y calificarlas.
- Crear tarea → botón "Nueva tarea"
- Ver entregas pendientes de calificar → pestaña correspondiente
- Calificar → abrir la entrega y dejar nota/feedback

## Pasos
«Nueva tarea» → título, instrucciones, fecha límite y alumnos o grupo → «Crear y asignar tarea». «Revisar entregas» → «Calificar entrega».

## Reglas
Calificación de 0 a 10, obligatoria, con retroalimentación opcional. Solo se califica una entrega enviada.

## Casos límite
Una tarea eliminada se archiva o borra según tenga entregas.

## Cuándo escalar
Si no se resuelve, abrir un ticket: enlace «Habla con soporte» del chat o «Nuevo ticket» en Soporte.
